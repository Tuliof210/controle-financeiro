# Colocar o teto como primeira leitura do dashboard

## Outcome

R1. Com o dashboard em `status: "ok"`, a faixa herói apresenta o teto do mês corrente (valor mensal) como cifra primária, no `MoneyDisplay` `variant="hero"`, com a taxa semanal visível na mesma faixa — não o saldo acumulado do fim do período.
R2. Na mesma faixa, o saldo projetado do último mês do período permanece visível como evidência secundária (tipo menor que o teto), com rótulo que o nomeia como projetado, não como teto.
R3. Com `status: "ok"`, o `CeilingCard` aparece no fluxo de leitura antes dos gráficos de `Overview` (`PeriodFacts` + `MonthlyBarChart` + `BalanceLineChart`).
R4. Estados `loading`, `no_range`, `out_of_range` e `error` continuam a renderizar o título da faixa e o `Notice` correspondente; a cifra do teto só aparece em `ok`.

- **Imitate** `src/app/_components/DashboardScreen/components/HeroBand/index.tsx` — a faixa é editorial (título, lede, uma resposta). COPY hoje:

```

vsSaldoAtual: "vs. saldo atual de",
```

A cifra herói vem de `buildFigures`: `valueCents: last.cumulative` (fim do período), não do teto.

- **Imitate** `src/app/_components/DashboardScreen/components/Board/index.tsx` — uma coluna, sem abas: `Overview` (facts + dois gráficos) depois `CeilingCard` depois `SavingsSection`.
- **Reuse** `useHeroBand` / `buildFigures` em `src/app/_components/DashboardScreen/components/HeroBand/` — hoje devolve `{ endLabel, valueCents, nowCents, deltaCents }`. A cifra primária passa a ser o teto já calculado no payload (`data.ceiling.monthly` e `data.ceiling.weekly`), o mesmo que o `CeilingCard` mostra.
- **Reuse** `MoneyDisplay` `variant="hero"` só na cifra primária (teto). A evidência projetada usa um variant menor já existente (`large` ou o equivalente não-hero).
- **Watch out for** o teste `HeroBand/tests/index.test.tsx` ainda afirma `"Saldo projetado em Mar/26."` como cifra da faixa e `Board/tests/index.test.tsx` afirma Overview antes do heading do teto — ambos têm de acompanhar R1–R3. Não recalcular teto no herói: o payload `ok` já traz `ceiling` para o `cap` corrente. `HeroBand` hoje só recebe o payload `ok` via `heroData`; precisa do `ceiling` desse mesmo objeto. Cap e simulação continuam no `DashboardScreen`; este prompt não persiste cap nem pinta simulação (isso é `260823-2121`). `PeriodFacts` continua no `Overview` (isso é `260823-2122`).

## Design

- **Contract** — `buildFigures` (ou sucessor) em payload `ok` devolve, no mínimo:

```
{
  monthLabel: string;       // mês corrente do range
  monthlyCents: number;     // data.ceiling.monthly
  weeklyCents: number;      // data.ceiling.weekly
  endLabel: string;         // último mês do período
  projectedEndCents: number;// points.at(-1).cumulative
  nowCents: number;         // cumulative do mês corrente
  deltaCents: number;       // projectedEndCents - nowCents
}
```

Faixa: (1) título da página; (2) lede que pergunta quanto ainda dá para gastar agora; (3) teto mensal como herói + taxa semanal; (4) linha de evidência com o saldo projetado em `endLabel` e o vs. saldo atual. `Board`: `CeilingCard` filho antes de `Overview`.

- **Flow** — `no_range` / `out_of_range` / erro: faixa sem cifras, `Notice` inalterado. `refreshing`: a faixa continua a marcar espera como hoje (`waiting` / `refreshing`).
- **Chose** dois números na mesma faixa (teto primário, projetado evidência) **over** mandar o acumulado só para o gráfico — o dono pediu os dois no herói, teto primeiro.
- **Chose** reordenar `Board` (teto antes dos gráficos) **over** fundir `CeilingCard` no herói — a tabela sufixo-mínimo e o `CapSelector` continuam no card instrumento.

## Steps

1. Passar o teto do payload `ok` para a faixa e torná-lo a cifra `hero`; o acumulado do fim do período vira evidência rotulada na mesma faixa. → R1 R2 R4
2. Reordenar `Board` para `CeilingCard` antes de `Overview`. → R3
3. Atualizar testes de `HeroBand`, `Board` e `DashboardScreen` para a nova primeira leitura. → R1 R2 R3 R4

## Scope

- In: `src/app/_components/DashboardScreen/` (faixa, `buildFigures`, `Board`, testes desses).
- Out: persistência do cap, default Meta, rótulo visível da simulação, `PeriodFacts` 3-up, nav, OFX, `EntryScreen`, `SavingsSection`, fórmula de `ceiling`.

## Forbidden

- Não alterar `src/lib/ceiling-caps.ts` nem `buildCeiling`.
- Não persistir `cap` nem mudar `DEFAULT_CEILING_CAP`.
- Não remover `/ofx-decoder` do `NAV`.
- Não introduzir dependência nova. Arquivos em `src/` no teto de 100 linhas.
