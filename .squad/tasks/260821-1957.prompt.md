# Portar primitivos de dinheiro e superfície do DS

## Outcome
R1. Dado qualquer valor em centavos na UI (dashboard, teto, poupança, listas), ele é renderizado por `MoneyDisplay` (não `MoneyFigure`); hero/large esmaecem os centavos com `--money-decimal-opacity`; o sinal negativo é U+2212.
R2. Dado um lançamento de despesa em `/movimentacoes` ou `/previsoes`, o valor não usa `--color-negative`; vermelho fica para variação negativa e ações destrutivas. A série “Saídas” dos gráficos do dashboard também não usa `--color-negative`.
R3. Dado uma previsão com `simulated: true`, o selo visível é `ProjectionBadge` `kind="simulado"` (rótulo + borda tracejada cobalto, não só cor). Kind `fixed`/`commitment` continua um `Badge` distinto — não colapsar os dois conceitos.
R4. Dado um card de produto (`SectionCard` e superfícies equivalentes), a casca visível é o primitivo `Card` (`flat` | `elevated` | `sunken` | `outline`); não há uma segunda pele de card paralela.
R5. Dado um delta de KPI (HeroBand, StatCard), o sinal + seta vêm de `Delta` (`invert` quando queda é boa).

## Design
- **Contract — MoneyDisplay** `src/components/MoneyDisplay/`:

```ts
export type MoneyDisplayProps = {
  value: number; // centavos
  variant?: "hero" | "large" | "base" | "small" | "delta"; // default "base"
  showPositiveSign?: boolean;
  colorBySign?: boolean; // default false
  dimDecimals?: boolean; // default true para hero|large
  hideSymbol?: boolean;
  hideCents?: boolean;
};
```

Sem `currency`/`locale`/`color` string do kit — o produto é BRL/pt-BR e cor vem de token, não de prop CSS. Internamente só `splitMoney`/`formatMoney`. Hero/large: `--font-sans`, `--money-hero`/`--money-large`, fraction com `opacity: var(--money-decimal-opacity)`. Apagar `MoneyFigure/`.

- **Contract — Delta** `src/components/Delta/`:

```ts
export type DeltaProps = {
  value: number; // pontos percentuais ou centavos
  percent?: boolean; // default true
  money?: boolean; // se true, formata via MoneyDisplay variant="delta"
  invert?: boolean; // queda boa (despesa)
  showArrow?: boolean; // default true — Icon trendingUp/trendingDown
  neutralThreshold?: number; // default 0
  size?: "sm" | "md" | "lg";
};
```

Up = `--color-positive`, down = `--color-negative`, |value| ≤ threshold = muted. Minus Unicode. Substitui glyphs ▲/▼ do HeroBand.

- **Contract — ProjectionBadge** `src/components/ProjectionBadge/`:

```ts
export type ProjectionKind = "real" | "estimado" | "simulado";
export type ProjectionBadgeProps = {
  kind?: ProjectionKind; // default "real"
  size?: "sm" | "md";
  showIcon?: boolean; // default true — check / calendar / sparkles
  children?: ReactNode; // override do label
};
```

Label default: `"Real"` / `"Estimado"` / `"Simulado"`. Forma: solid / dotted / dashed-cobalt via `--proj-*`. Nunca só cor.

- **Contract — Badge** `src/components/Badge/`:

```ts
export type BadgeProps = {
  tone?: "neutral" | "positive" | "negative" | "alert" | "info" | "ai" | "cobalt";
  variant?: "soft" | "solid" | "outline";
  size?: "sm" | "md";
  icon?: MvIconName;
  dot?: boolean;
  scope?: "PF" | "PJ" | string;
  principal?: boolean;
  children: ReactNode;
};
```

Forecast kind → `<Badge tone="neutral">`. Não usar `scope`/`principal` até existir PF/PJ na UI.

- **Contract — Card** `src/components/Card/`:

```ts
export type CardProps = {
  variant?: "flat" | "elevated" | "sunken" | "outline"; // default "flat"
  padding?: "sm" | "md" | "lg"; // --space-4 / --space-5 / --space-6; default "md" (= 20px)
  interactive?: boolean; // hover: translateY(-1px) + --elevation-overlay
  as?: keyof JSX.IntrinsicElements; // default "div"
  children: ReactNode;
};
```

Sem `padding: number` nem `radius: string` do kit — radius sempre `--radius-lg`. Flat = superfície + hairline, sem sombra. Elevated = `--elevation-raised`. Sunken = `--color-surface-raised` (light: sunken `--color` mapped). Outline = transparente + hairline.

`SectionCard` renderiza `<Card variant={band ? "elevated" : "flat"}>` e mantém title/icon/hint/headerEnd/band.

- **Flow** — ForecastBadges: `[Badge(kind), simulated && ProjectionBadge({ kind: "simulado" })]`. Charts: inalterados na forma; fill de saídas → `--color-text-secondary` (mesmo raciocínio do chipNeutral de StatCard).
- **Chose** `padding` como step de espaço **over** px cru do kit — regra “never hardcode”.
- **Chose** não portar `currency`/`locale` **over** API morta — um só locale.
- **Chose** SectionCard como composição **over** dois sistemas de card.
