# Traçar o teto no saldo acumulado

## Outcome
R1. No gráfico **Saldo acumulado**, a série de hoje (`points[].cumulative`) permanece, e a
    partir do mês corrente aparece uma segunda série igual a `ceiling.months[].ceilingLeft`
    — o mesmo número da coluna **Sobra** da tabela do teto (saldo se cada mês gastar o
    teto). Meses sem linha em `ceiling.months` (antes do corrente) não têm segunda linha.
    Com `budget === 0` naquele mês, as duas coincidem.
R2. A série atual usa `--color-brand`; a do teto usa `--color-text-secondary`. A legenda
    nomeia **Atual** e **Se gastar o teto** e mantém a nota
    `sólida = realizado · tracejada = projeção`. Só a linha atual é tracejada. A mancha
    sob a curva e o marcador **MÊS MAIS APERTADO** ficam na linha atual, em `cumulative`.
R3. O tooltip de qualquer ponto daquele mês lista os dois valores quando o mês tem teto;
    o nome acessível de cada ponto nomeia a própria série. O domínio Y inclui as duas
    séries: um `ceilingLeft` negativo (teto fixo acima do headroom) não corta a linha e
    acende a linha de zero.

## Context
A tabela do teto já é essa hipótese. Não recalcular: só plotar `ceilingLeft`.

## Design
- **Contract** — prop nova no gráfico, sem campo novo em `MonthPoint` e sem mudança de
  `GET /api/dashboard`:
  ```ts
  interface BalanceLineChartProps {
    points: MonthPoint[];
    dashedFrom: number | null;
    tightest: number | null;
    ceilingMonths: CeilingMonth[]; // Ceiling.months; [] = só a linha atual
    width: number;
    height: number;
  }
  ```
  Overview: `ceilingMonths={data.ceiling.months}`.

  Legenda do card Saldo acumulado:
  ```ts
  items: [
    { key: "current", label: "Atual", color: "var(--color-brand)" },
    { key: "teto", label: "Se gastar o teto", color: "var(--color-text-secondary)" },
  ]
  note: "sólida = realizado · tracejada = projeção"
  ```

  Stroke da série teto (ao lado de `LINE_PROPS`):
  `{ stroke: "var(--color-text-secondary)", strokeWidth: 2 }` — sem `strokeDasharray`.

  Tooltip, mês presente em `ceilingMonths`:
  ```ts
  rows: [
    { key: "cumulative", label: "acumulado", value: formatMoney(cumulative), tone: "brand" },
    { key: "teto", label: "se gastar o teto", value: formatMoney(ceilingLeft), tone: "neutral" },
  ]
  ```
  Mês sem teto: a row `acumulado` só. Tag `real` / `estimado` continua vindo de
  `dashedFrom` (qualidade do mês), não do cenário. Títulos acessíveis: `Jan/26 · acumulado R$ 1,00`
  e `Jan/26 · se gastar o teto R$ 0,40` — cada ponto nomeia a própria série.

  `HINTS.cumulative`: o texto atual mais a segunda linha, sem recontar o teto. Tracejado
  continua "projeção na linha atual".

  Pintura: path do teto *embaixo* da série atual, para o overlap (`budget === 0`) continuar
  lendo como atual. Wash (`areaWashProps`) só sob `cumulative`.

- **Flow** — um hover, um bubble. Qualquer um dos dois dots do mês dispara o mesmo
  `TooltipContent`. Sem segundo tooltip.

- **Chose `ceilingLeft` over `ceilingBalance`** — "caso o gasto se cumpra" é o saldo
  *depois* de gastar o teto; é a Sobra, não o saldo que chega.
- **Chose `ceiling.months` over campo em `MonthPoint`** — a hipótese é do teto (sufixo
  desde o mês corrente), não do mês reconciliado; `period-facts` e as barras leem
  `cumulative`/`income`/`expense` e não podem herdar um campo vazio no passado.
- **Chose cor over tracejado na série teto** — o dash já significa estimado/projeção.
- **Chose não dashar a série teto em `dashedFrom`** — quatro segmentos com o mesmo
  vocabulário visual; a cor + a legenda já separam o cenário.
