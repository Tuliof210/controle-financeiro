# Portar chrome e forms do DS Monevo

## Outcome
R1. Dado o app em qualquer rota autenticada, o mark do Aside e o favicon são o símbolo M em barras de `design-system/assets/` (não o SVG pixel-block), e não há import de `lucide-react`.
R2. Dado um botão na UI, as variantes visíveis são `primary` | `secondary` | `ghost` | `destructive` | `dashed`; não existe `danger` nem `success`; `iconLeft`/`iconRight` aceitam `MvIconName`; tamanhos `sm` | `md` | `lg`.
R3. Dado um formulário (EntryForm, GoalForm, PersonForm, EntryListControls, ImportAction, SpendingGoalSection), o campo de texto é `Field` e o de dinheiro é `Field money`; o select é `Select`; `TextField`, `SelectField` e `MoneyInput` não existem. Digitar centavos no modo money ainda é o odômetro (caret à direita, `formatCents` inalterado).
R4. Dado o Header, o avatar do perfil ativo usa `src/components/Avatar` com o nome da pessoa e `color: var(--cat-<palette-key>)`; sem `src`, mostra iniciais.
R5. Storybook lista uma página MDX por primitivo novo ou reescrito nesta tarefa (Icon, Button, Field, Select, Avatar).

## Design
- **Contract — tokens** (namespace do app `--*`, nunca `--mv-*`):
  - `--ai-fg` `#6D45C7` / `--ai-bg` `#EEE8FB` / `--ai-border` `#D6C8F2` em `_tokens-color.scss`; trio dark derivado como os doze existentes (fg ≥ 4.5:1 no próprio wash e em `--neutral-800`). Aliases `--color-ai` em `_tokens-theme.scss` + mixin dark.
  - `--money-hero` `3rem` / `--money-large` `1.875rem` / `--money-base` `1.0625rem` / `--money-small` `0.875rem` / `--money-delta` `0.8125rem`; `--money-decimal-opacity: 0.45`. Face de dinheiro: `--font-sans` em todas as variantes (constituição: grotesque em todo money; o kit DS usa Clash no hero — não copiar).
  - `--proj-real-fg/bg`, `--proj-est-fg/bg`, `--proj-sim-fg/bg` (valores light = kit `--mv-proj-*`). Borda: real `var(--border-1) solid var(--color-border-strong)`; estimado `1.5px dotted var(--neutral-400)`; simulado `1.5px dashed var(--cobalt-300)`. Dark: inverter fg/bg no mixin.
  - `--duration-instant: 80ms` em `_tokens-motion.scss`, zerado no `prefers-reduced-motion`.
- **Contract — `MvIconName`**: os 27 do kit (`wallet` `card` `target` `trendingUp` `trendingDown` `arrowUpRight` `arrowDownRight` `plus` `minus` `repeat` `calendar` `alertTriangle` `sparkles` `eye` `lock` `check` `x` `chevronDown` `chevronRight` `archive` `search` `settings` `bell` `user` `building` `pieChart` `banknote`) **mais** os glifos de produção sem par: `pencil` `trash` `arrowDownCircle` `arrowUpCircle` `layoutDashboard` `scale` `chevronUp` `chartColumn` `fileText` `info` `fileUp` `listTree` `menu` `moon` `sun` `panelLeftClose` `panelLeftOpen` `users` `upload` `arrowLeftRight`. Novos paths no mesmo grid/stroke; não reexportar SVG da lucide.
- **Contract — Icon** `src/components/Icon/`:

```ts
export type IconProps = {
  name: MvIconName;
  size?: number; // default 20
  strokeWidth?: number; // default 1.75
  title?: string;
} & SVGProps<SVGSVGElement>;
```

`MV_ICONS: Record<MvIconName, string>` pode viver em `icons.ts` + partials se estourar 100 linhas.

- **Contract — Button**:

```ts
type Variant = "primary" | "secondary" | "ghost" | "destructive" | "dashed";
type Size = "sm" | "md" | "lg"; // altura 36 / 44 (--size-tap) / 52
export type ButtonProps = {
  variant?: Variant; // default "primary"
  size?: Size; // default "md"
  iconLeft?: MvIconName;
  iconRight?: MvIconName;
  fullWidth?: boolean;
  loading?: boolean;
} & ButtonHTMLAttributes<HTMLButtonElement>;
```

Primary: fill `--color-brand`, texto `--white` (não `--color-bg`). Destructive: fill `--color-negative`, texto `--white`. Secondary: superfície + hairline. Ghost: sem fill. `dashed` permanece — affordance “Adicionar…” do app; o kit não tem equivalente. Press `scale(0.985)`. `danger` → `destructive` em todos os call sites. IconButton: `variant?: "ghost" | "destructive"`; children são `<Icon name=… />`.

- **Contract — Field** (substitui TextField + MoneyInput), união discriminada:

```ts
type FieldBase = {
  id: string;
  label: string;
  placeholder?: string;
  hint?: string;
  error?: string;
  disabled?: boolean;
  required?: boolean;
  iconLeft?: MvIconName;
  maxLength?: number;
};
export type FieldProps =
  | (FieldBase & { money?: false; value: string; onChange: (value: string) => void })
  | (FieldBase & { money: true; value: number; onChange: (value: number) => void; ariaLabel?: string });
```

`label` e `id` obrigatórios (a11y; o kit deixa opcional). Money: `value` em centavos; display via `formatCents`; caret pinado à direita como `useMoneyInput`. Não aceitar `onChange: any`.

- **Contract — Select** (substitui SelectField):

```ts
export type SelectOption = { value: string; label: string };
export type SelectProps = {
  id: string;
  label: string;
  value: string;
  options: SelectOption[];
  onChange: (value: string) => void;
  placeholder?: string;
  hint?: string;
  error?: string;
  disabled?: boolean;
  required?: boolean;
};
```

`onChange` continua `(value: string) => void` — não o evento nativo do kit. Reexportar `SelectOption` no lugar de `SelectFieldOption` (`EntryListControls/hook.ts`, `EntryScreen/list.hook.ts`).

- **Contract — Avatar** `src/components/Avatar/`:

```ts
export type AvatarProps = {
  name?: string;
  src?: string;
  size?: "sm" | "md" | "lg" | "xl" | number; // md = 36
  shape?: "circle" | "square"; // default "circle"
  color?: string; // CSS value, e.g. var(--cat-violet)
};
```

Sem `src`: iniciais first+last. Sem `color`: hash do `name` sobre as 7 keys de `PALETTE`. `role="img"` + `aria-label={name}` quando nome existe; Header deixa de ser `aria-hidden`. Header passa `name` da pessoa ativa e `color: var(--cat-${person.color})`.

- **Flow** — money Field: a cada dígito, `digitsToCents` → `onChange(cents)` → re-render `formatCents` → caret no fim. Falha de validação é `error` string, borda `--negative-border`. Não mudar o teto `MAX_CENTS`.
- **Chose** pasta `src/components/` + tokens `--*` **over** importar `design-system/` ou prefixo `--mv-*` — o app já tem constituição em `src/styles/`.
- **Chose** lucide fora **over** dois sets de ícone. Cobertura do kit é incompleta; estender `MvIconName` em vez de deixar lucide no dashboard.
- **Chose** `dashed` no Button **over** forçar secondary no “Adicionar…” — a affordance pontilhada já é vocabulário do produto.
- **Chose** `onChange` controlado em Field/Select **over** evento nativo do kit — um só dialeto com os forms atuais.
