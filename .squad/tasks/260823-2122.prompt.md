# Tirar o decoder do nav e enxugar o dashboard

## Outcome

R1. `NAV` tem cinco destinos, nesta ordem: `/`, `/movimentacoes`, `/previsoes`, `/leitor-ofx`, `/configuracoes`. Não há entrada `/ofx-decoder`.
R2. A rota `/ofx-decoder` não aparece em navegação primária (Aside, drawer). O arquivo da rota pode permanecer, mas nenhum link do chrome aponta para ela.
R3. O `PageHeader` de `/leitor-ofx` descreve o leitor como correção da projeção (totais do extrato viram movimentações e atualizam o teto), não só como leitura local privada.
R4. Em dashboard `ok`, não há o card 3-up `PeriodFacts` (“No período” com Entradas / Saídas / Meses no vermelho como KPIs iguais). Os dois gráficos permanecem, abaixo do `CeilingCard` se `260823-2120` já rodou.

## Context

Pode correr depois de `260823-2120` (teto já acima dos gráficos). Não implementa o aviso de irreversibilidade nem o redirect pós-import (`260823-2123`).

- **Imitate** `src/app/leitor-ofx/_components/OfxScreen/index.tsx` — subtitle hoje: `"Leia o extrato do banco direto no navegador, sem subir nada."`
- **Imitate** `src/app/_components/DashboardScreen/components/Overview/index.tsx` — `PeriodFacts` é o primeiro filho; depois os dois `ChartCard`.
- **Imitate** `PeriodFacts` — card “No período” com três `dt`/`dd`. Comentário no próprio arquivo: evidência do herói, não uma fileira de KPI tiles — na prática compete com o teto.
- **Watch out for** `src/components/AppShell/tests/nav.test.ts` lista seis hrefs incluindo `/ofx-decoder`. `PageHeader` comenta “all five screens” enquanto o rail tem seis — depois deste prompt os dois batem em cinco. Não apagar `src/app/ofx-decoder/` neste prompt (ferramenta de operador fora do produto). `UploadCard` do leitor já explica que só totais confirmados vão ao banco — o header é que ainda soa só privacidade.

## Design

- **Contract** — `NAV` final:

```
[
  { href: "/", label: "Dashboard", … },
  { href: "/movimentacoes", … },
  { href: "/previsoes", … },
  { href: "/leitor-ofx", label: "Leitor OFX", … },
  { href: "/configuracoes", … },
]
```

Subtitle do leitor (sentido, não prosa livre): o extrato corrige a projeção; totais mensais vira movimentações; o teto passa a usar esses fatos. `Overview` deixa de montar `PeriodFacts`. Totais de período, se ainda forem necessários, cabem na legenda/caption dos gráficos, não num card de três KPIs.

- **Chose** deslistar o decoder **over** deletar a rota — o dono ainda pode abrir `/ofx-decoder` na URL; o produto não oferece a ferramenta.
- **Chose** remover `PeriodFacts` **over** comprimi-lo numa linha no herói — o herói já responde o teto (`260823-2120`); o 3-up é o anti-padrão SaaS da auditoria.
