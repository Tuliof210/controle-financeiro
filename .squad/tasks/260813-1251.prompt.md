## Outcome

    cada uma das três faces fica no papel que `ARCHITECTURE.md` e `src/styles/README.md`

    ficam dentro do plot em qualquer largura, e um mês simulado nunca lê igual a um mês
    estimado.

    corrigidas por esta task removidas, prosa obsoleta atualizada, e as recompensas

## Design

- **Contrato — `useHeroBand`.** `figures` troca as três chaves de delta por um veredito
  e a manchete passa a ser o teto:

  ```ts
  type HeroVerdict = {
    tone: "positive" | "caution" | "negative";
    sentence: string;
    limit: string | null; // limitLabel(byMeta, ceiling.tightest)
  };

  // figures, quando data?.status === "ok"
  {
    value: number;      // data.ceiling.monthly (cents) — era last.cumulative
    verdict: HeroVerdict;
    facts: Fact[];      // ganha uma 4ª entrada
  }
  ```

  Os três ramos, na ordem em que devem ser testados:

  | condição | tone | sentence | limit |
  |---|---|---|---|
  | `ceiling.firstRed !== null` | `negative` | `${formatYyyymm(firstRed.month)} já fecha negativo em ${formatMoney(firstRed.shortfall)}.` | `null` |
  | `firstRed === null && ceiling.monthly === 0` | `caution` | `Nenhum gasto extra cabe neste mês.` | `limitLabel(...)` |
  | `ceiling.monthly > 0` | `positive` | `Dá para gastar sem nenhum mês fechar negativo.` | `limitLabel(...)` |

  A frase **não repete a cifra** — a cifra é a manchete logo acima, e imprimir os dois
  é a duplicação que `MoneyFigure` existe para evitar.

  `byMeta` sai do mesmo predicado que `CeilingCard/hook.ts` já calcula. Se ele estiver
  inline lá, extraia para `ceiling-card.helper.ts` e faça os dois call sites lerem uma
  regra só — não escreva um segundo predicado.

- **Contrato — a manchete é `dl`/`dt`/`dd`**, como `Facts` (audit P2-3): o eyebrow
  "Teto deste mês" é o `<dt>`, a `MoneyFigure` é o `<dd>`. Deixar dois `<p>` irmãos é o
  defeito.

- **Contrato — 4ª entrada de `buildFacts`.** A assinatura passa a
  `buildFacts(points: MonthPoint[], range: DashboardRange)`:

  ```ts
  { key: "projected", label: "Saldo projetado",
    value: formatMoneyShort(points.at(-1).cumulative), sub: formatYyyymm(range.end) }
  ```

  Os rótulos das quatro entradas ficam em **sentence case na fonte**; o CAIXA ALTA vem
  de `text-transform: uppercase` no CSS (R3). `ENTRADAS ${months}M` vira
  `Entradas ${months}m`.

- **Contrato — `MonthPoint.simulated`.** Campo novo no payload:

  ```ts
  simulated: boolean; // a simulated forecast contributed to this month's figures
  ```

  `true` sse ao menos uma previsão que alimenta o mês tem `simulated === true`. Na view
  `real` as simulações já são filtradas antes, então é `false` em todo mês — a flag só
  fica quente com `?simulation=all`.

  Os dois `tagFor` ganham um terceiro resultado, `"simulado"`, com precedência sobre
  `"estimado"`. `line-dot.helper.ts` passa a `tagFor(projected: boolean, simulated: boolean)`.

  **A palavra não basta** — README rule 7: significado nunca só por cor, e o audit
  registra que real-vs-projetado já sobrevive em três canais. Um mês simulado ganha um
  quarto traço próprio: constante de traço **pontilhado** em `chart-marks.config.ts`,
  distinta do tracejado que já marca projeção, aplicada à barra e ao dot. O nome do mark
  acessível também carrega a palavra.

- **Contrato — `Stats` encolhe.** `median` e `stdDev` saem do tipo, de
  `stats.helper.ts` e dos testes; as linhas do `StatCard` vão de quatro para duas
  (`Realizado`, `Média/mês`). A sparkline sai inteira: `spark.helper.ts`, `SPARK_W`,
  `SPARK_H`, o `<svg>` de `StatCard/index.tsx`, o prop `series`, o mapa `TONE_COLOR`, a
  chave `color` e os três `.map` de `Overview/hook.ts`.

  **Escolhi deletar do payload em vez de só parar de renderizar** — campo que ninguém lê
  é campo morto, e `Stats` só tem estes três consumidores. A alternativa (manter
  `median`/`stdDev` no read model para um consumidor futuro) é a flexibilidade
  especulativa que o cap de linhas existe para punir.

- **Contrato — dois mixins em `src/styles/_theme.scss`**, ao lado de `focus-ring`, `bp`,
  `elevation` e `skin` (debt `:36`, `:43`, `:53`):

  ```scss
  @mixin micro-label { /* mono, --text-2xs, --tracking-wide, uppercase,
                          --color-text-muted, font-variant-numeric: tabular-nums */ }
  @mixin visually-hidden { /* position: absolute; width: 1px; height: 1px;
                              overflow: hidden; clip-path: inset(50%) */ }
  ```

  Todo site duplicado passa a incluir. `CapSelector/style.module.scss:38` usa hoje uma
  receita **diferente** (`opacity: 0`, sem `clip-path`) sob comentário afirmando ser a
  mesma — converge para o mixin ou o comentário para de mentir.

- **Escolhi corrigir o código em vez de emendar o DESIGN.md** nos três pontos onde o
  critique aponta que a regra perdeu (`<th>` em caixa alta, eyebrow em todo rótulo,
  eyebrow em `--font-display`). O bloco `FOR REVIEW` de
  `MonthTable/style.module.scss` fecha citando esta task.

- **Escolhi manter as quatro superfícies `band="ink"`** (`HeroBand`, `ChartCard` ×2,
  `CeilingCard`). O que está errado é o comentário de `HeroBand/style.module.scss`
  afirmando ser "the only surface on the dashboard that flips" — corrija a frase, não a
  composição: de-inkar dois cards é redesenho, não correção de achado.
