## Design Specificity Verdict

**LLM:** Autoral nos detalhes (CeilingCard, CoverageBar, ProjectionBadge, CapSelector, max(real, estimated) nos HINTS, MoneyDisplay, HeroBand invertida). Intercambiável na IA: rail de 6 pares, greeting SaaS, 3 KPIs, dois gráficos obrigatórios, settings-as-CRUD, dois uploaders OFX. A frase de abertura (“Onde o dinheiro da família está hoje e para onde ele vai”) é a anti-referência nomeada — app de banco. O número que o produto existe para produzir não é o primeiro que a composição diz.

**Deterministic scan:** src/app 0 achados (exit 0). src/components 1 warning `layout-transition` em `Aside/style.module.scss:29` (`transition: width`). Em markup: zero. Falso positivo relativo ao escopo de markup (CSS-only); o stylesheet é produção real. O detector confirma: o problema não é CSS sujo.

**Visual overlays:** não há overlay visível. Mutation indisponível (browser MCP sem aba usável). Fallback: screenshots Playwright de `/`, `/previsoes`, `/movimentacoes`, `/configuracoes`, `/leitor-ofx` confirmam herói Dez/27, dois gráficos acima do teto, Decoder no rail.

## Priority Issues

**[P1] Dashboard answers the wrong question first** — HeroBand “Saldo projetado em Dez/27 · R$ 80.006,88”. Job number is CeilingCard R$ 6.767,44 (or Meta R$ 2.000). Board puts PeriodFacts + two charts above teto. Fix: hero IS the teto. Suggested: `$impeccable distill` then `$impeccable layout`.

**[P1] Four answers look like the same kind of fact** — cumulative, 24-month totals, teto at unpersisted 50%, savings capacity R$ 1.123,70. Saved Meta does not bind by default. Fix: one primary figure; cap default honors Meta. Suggested: `$impeccable clarify`.

**[P1] /ofx-decoder in product nav; OFX import is a side tool** — Sixth rail item, English, same DropZone. Leitor subtitle is privacy, not “this corrects the ceiling”. No undo sentence. Fix: remove Decoder; reframe Leitor; warn irreversibility; return to dashboard. Suggested: `$impeccable distill`.

**[P2] Forecast write does not match the mental model** — Interval ranges + inert KindToggle + Simulação, all in a modal so teto impact is invisible. Fix: month chips; kind optional; preview teto delta. Suggested: `$impeccable shape` / `$impeccable clarify`.

**[P2] Header profile is a silent filter; write is four nav items from the number it changes** — Família vs Tulio with one person; empty movements blame a filter with no on-page control; forms re-ask Responsável. Fix: name the filter; one owner control; add from dashboard with teto visible. Suggested: `$impeccable layout`.

## Five axes

### Data
Makes sense: plan vs actual; derived period; simulated opt-in; ceiling table as proof.
Doesn't: hero = last cumulative; 24-month totals before teto; inert kind; Decoder as data surface.

### Graphic / interactive
Makes sense: inverted band, rationed cobalt, solid vs dashed, one control grammar.
Doesn't: SaaS widget stack; 6 nav peers; unlabeled simulation select; red routine expenses; greeting theater.

### Read / write
Makes sense: shared EntryScreen; profile filters both; settings in the right place.
Doesn't: write hides teto; dual owner control; OFX doesn't return; cap doesn't persist.

### Dashboard clarity
Makes sense: editorial anatomy; “gasto extra este mês”; empty/error states.
Doesn't: 3 seconds ≠ spend now; four figures same shout; Meta not default.

### Value gaps
Makes sense: ceiling, simulation, goal pace, OFX dedupe.
Doesn't: no “can I buy X?”; no post-write teto delta; silent OFX no-undo; Família vs Tulio unexplained; Decoder; three funding models as spreadsheet; no “what changed since last open”.
