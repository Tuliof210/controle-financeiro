# controle-financeiro

## Mandatory first step

Before answering anything in this repository — a `/ps:*` command or an ordinary
question, every session, every message — read `.squad/PRODUCT.md` and
`.squad/ARCHITECTURE.md`. They are the norm this project is judged against.

## Stack
- Next.js 16 (App Router) — single app serving both the frontend and the API
  (Route Handlers), TypeScript, React 19
- SQLite via **Prisma 7** (`@prisma/adapter-better-sqlite3`) — local file-based
  database, no server process. Client generated to `src/generated/prisma`
  (gitignored); `DATABASE_URL` comes from `.env` (see `.env.example`)
- Sass Modules — component styling (`.module.scss`)
- Design System foundations — tokens + rules in `src/styles/` (see
  `src/styles/README.md`); documented as Storybook Foundations MDX docs
  (`.storybook/`, `src/styles/docs/`) — no DS components yet
- visx — charts (`@visx/shape`, `scale`, `axis`, `group`)
- lucide-react — icons
- Biome — lint & format (gates review, see .squad/ARCHITECTURE.md)
- Playwright — the only test runner; end-to-end tests only (specs in `e2e/`)
- Zod — request validation
- UI copy and route paths are pt-BR (`/movimentacoes`, `/previsoes`,
  `/configuracoes`, `/leitor-ofx`); code identifiers and docs are English
- Runs entirely on the user's local machine (not deployed)

## Commands
- `npm run db:setup` — `prisma generate` + `prisma migrate deploy`; creates the
  local SQLite tables (idempotent; run once after `npm install` on a fresh
  checkout)
- `npm run dev` — start the local dev server
- `npm run build` — production build; `npm run start` — serve that build
- `npm run lint` — **two** gates: `biome check .` then `npm run lint:lines`
  (`scripts/check-line-cap.sh`, the 100-line cap). Both must pass
- `npm run lint:fix` — `biome check --write .`; `npm run format` — format only
- `npm run db:clean` — DELETE every row from every table in `dev.db`
- `npx playwright install chromium` — download the browser Playwright drives
  (run once after `npm install` on a fresh checkout)
- `npm run test:e2e` (aliased as `npm run test`) — Playwright; boots its own
  dev server on :3100 against a throwaway `e2e.db`, never `dev.db`. Specs go
  in `e2e/`
- `npm run storybook` — Storybook dev server (Foundations MDX docs, :6006)
- `npm run build-storybook` — static Storybook build

## Do-not-touch
- `src/generated/prisma/` — regenerated by `prisma generate`; never hand-edit,
  never count against the line cap
- `prisma/migrations/` — applied history; add a new migration, never edit one

Squash-merging a reviewed `task/*` PR and deleting that branch is this
