# Motion

Calm and precise: short fades and slides, no bounce, nothing euphoric. Every
duration token collapses to `0ms` under `prefers-reduced-motion: reduce` —
motion is opt-out by the OS, not by each component.

## Easings

`--ease-snappy: cubic-bezier(0.2, 0, 0, 1)` — the default for UI transitions.
`--ease-out: cubic-bezier(0.16, 1, 0.3, 1)` — for something entering the
screen, where the tail should settle rather than stop.

## Focus

`--focus-ring` is a translucent cobalt ring derived from `--color-focus` with
`color-mix`, so it follows the theme on its own. `@include t.focus-ring;`
paints it over a **transparent** outline — that outline is the forced-colors
escape hatch, and dropping it makes the ring vanish in high contrast.
