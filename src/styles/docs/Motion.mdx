# Motion

Short, snappy durations with an optional 8-bit `steps()` easing for specific
micro-interactions. Every duration token collapses to `0ms` under
`prefers-reduced-motion: reduce` — motion is opt-out by the OS, not by each
component.

## Easings

`--ease-snappy: cubic-bezier(0.2, 0, 0, 1)` — the default for UI transitions.
`--ease-step: steps(4, end)` — optional 8-bit flavor for specific
micro-interactions only, not the default.
