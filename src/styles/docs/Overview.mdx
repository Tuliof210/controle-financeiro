# Design System — Foundations

This Storybook documents the DS **constitution only** — the non-negotiable
tokens and rules every future component must follow. There are no components
here yet; use the toolbar's theme toggle to flip every page below between
light and dark.

## Non-negotiable rules

1. **Never hardcode** a color, spacing, radius, shadow, or duration value —
   always a token. `src/app/icon.svg` is the one documented exception.
2. **Radius is chosen by surface type** — cards `lg` 14, controls `md` 10, chips
   `sm` 6, pills/tracks/dots/avatars `full`, sheets `xl` 20. An inner corner
   flush inside an outer one is derived with `calc()`, never a second literal.
   `--border-1` is structural; `--border-2` is emphasis only.
3. **Elevation is border-first.** Shadow only when the layer genuinely floats:
   `--elevation-overlay` for dropdown/popover/sheet, `--elevation-modal` for
   the modal. The hard offset shadows are gone; a control's press is
   `transform: scale(0.985)`.
4. **Three faces, one job each.** `--font-display` (Clash Display) heros and
   titles, `--font-sans` (Hanken Grotesk) body, labels and money,
   `--font-mono` (IBM Plex Mono) eyebrows, IDs, dates and hex.
5. **Spacing comes only from the 4px scale**, and hit targets are at least
   `--size-tap`.
6. **Every semantic token exists in both themes** — the `:root` block in
   `_tokens-theme.scss` and `@mixin dark-theme` in `_tokens-dark.scss`, which
   is the single source both dark selectors read.
7. **Accessibility is non-negotiable**: visible focus rings, ≥4.5:1 text
   contrast with the measured ratio written beside the token, meaning never
   color-only, `prefers-reduced-motion` respected.
8. **No decorative gradients**, no glassmorphism, no texture. `--glow-brand`
   is the only authorised gradient.

See `src/styles/README.md` for the full constitution.
