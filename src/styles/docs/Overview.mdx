# Design System — Foundations

This Storybook documents the DS **constitution only** — the non-negotiable
tokens and rules every future component must follow. There are no components
here yet; use the toolbar's theme toggle to flip every page below between
light and dark.

## Non-negotiable rules

1. **Never hardcode** a color, spacing, radius, shadow, or duration value —
   always a token.
2. **Radius never exceeds `--radius-lg` (6px).** `--radius-full` is avatars
   and status dots only.
3. **Elevation is border-first.** Blur-shadow (`--elevation-overlay`) is
   reserved for floating layers only — menu, popover, modal, toast.
4. **One display face, one workhorse face.** `--font-display` (Press Start
   2P) is short display/eyebrow text only; everything else, including every
   number, is `--font-mono` (JetBrains Mono).
5. **Spacing comes only from the 4px scale.**
6. **Every semantic token exists in both themes** — enforced by
   `src/styles/tokens.test.ts`.
7. **Accessibility is non-negotiable**: visible focus rings, ≥4.5:1 text
   contrast, meaning never color-only, `prefers-reduced-motion` respected.

See `src/styles/README.md` for the full constitution.
