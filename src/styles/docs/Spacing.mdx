# Spacing

A closed 4px grid — no ad-hoc pixel values. Every gap, padding, and margin
in the app comes from one of these steps.

<div style={{ display: "flex", flexDirection: "column", gap: "var(--space-2)", background: "var(--color-surface)", padding: "var(--space-4)", borderRadius: "var(--radius-lg)" }}>
  {steps.map((name) => (
    <div key={name} style={{ display: "flex", alignItems: "center", gap: "var(--space-4)" }}>
      <code style={{ width: "11ch", flex: "none", fontSize: "var(--text-2xs)", color: "var(--color-text-muted)", fontFamily: "var(--font-mono)" }}>
        --{name}
      </code>
      <div style={{ height: "16px", width: `var(--${name})`, borderRadius: "var(--radius-sm)", background: "var(--color-brand)" }} />
    </div>
  ))}
</div>

## Hit targets

`--size-tap` (44px) is the floor for anything a reader presses. It is a token
now precisely because it was written as a raw `44px` in 23 places.
