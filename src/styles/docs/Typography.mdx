# Typography

One display face, one workhorse face. `--font-display` (Press Start 2P) is
for short titles/eyebrows only — never body copy, never long numbers.
Everything else, including every number, uses `--font-mono` (JetBrains Mono).

## Display — short text only

<div style={{ fontFamily: "var(--font-display)", fontSize: "var(--text-2xl)", letterSpacing: "var(--tracking-display)", lineHeight: "var(--leading-tight)" }}>
  CAIXA SAUDÁVEL
</div>

## Mono — everything else

<p style={{ fontFamily: "var(--font-mono)", fontSize: "var(--text-md)", lineHeight: "var(--leading-normal)", maxWidth: "42ch" }}>
  Compare o esperado com o que aconteceu no mês — este é o corpo de texto
  padrão da UI, sempre em --font-mono.
</p>

## Size scale

<div style={{ display: "flex", flexDirection: "column", gap: "var(--space-2)", fontFamily: "var(--font-mono)" }}>
  {sizes.map((name) => (
    <div key={name} style={{ display: "flex", alignItems: "baseline", gap: "var(--space-4)" }}>
      <code style={{ width: "8ch", fontSize: "var(--text-xs)", color: "var(--color-text-muted)" }}>
        --{name}
      </code>
      <span style={{ fontSize: `var(--${name})` }}>Aa 123</span>
    </div>
  ))}
</div>

## Weights

<div style={{ display: "flex", gap: "var(--space-6)", fontFamily: "var(--font-mono)", fontSize: "var(--text-lg)" }}>
  {weights.map((name) => (
    <span key={name} style={{ fontWeight: `var(--${name})` }}>
      Aa — --{name}
    </span>
  ))}
</div>

## Money — mono + tabular-nums (mandatory)

  R$ 1.234,56 · R$ 0,00 · −R$ 88,90
</div>
