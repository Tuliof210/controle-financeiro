# Elevation

Border-first, not shadow-first. A surface tier (`--color-surface`,
`--color-surface-raised`) plus a border is the default way to lift an
element. Blur-shadow (`--elevation-overlay`) is reserved for floating layers
only — menu, popover, modal, toast. **No hard offset shadows anywhere.**
