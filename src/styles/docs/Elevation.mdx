# Elevation

Border-first, not shadow-first. A surface tier (`--color-surface`,
`--color-surface-raised`) plus a border is the default way to lift an
element. Blur-shadow (`--elevation-overlay`) is reserved for floating layers
only — menu, popover, modal, toast.

The three hard offset shadows below are blur-less and cast in
`--color-border`, so they read as the frame displaced rather than as depth.
They are **scoped**, not general-purpose: `--elevation-press` and
`--elevation-press-active` belong to the primary action (resting, then
2px-displaced while pressed), `--elevation-panel` to the modal panel.
Nothing else gets one.

## Hard offset shadows

Each box below carries a `--border-2` frame, because these shadows are only
ever used on bordered surfaces — the shadow is that border, displaced. The
extra right/bottom margin is there so the offset has somewhere to land.
